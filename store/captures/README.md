# Captures d'écran App Store

Générées automatiquement avec une **classe fictive** (élèves inventés) :

```
flutter test tool/screenshots/screenshots_test.dart
```

| Dossier | Appareil App Store Connect | Taille |
|---|---|---|
| `iphone_6.9/` | iPhone 6,9 pouces | 1320 × 2868 |
| `ipad_13/` | iPad 13 pouces | 2064 × 2752 |
| `mac/` | Mac | 2880 × 1800 |

PNG sans transparence, comme l'exige Apple. Les glisser dans App Store Connect
(Distribution → la version → Aperçus et captures d'écran), dans l'ordre des numéros.

À régénérer après un changement visible de l'interface. Ne jamais remplacer par
des captures contenant de vrais élèves.
